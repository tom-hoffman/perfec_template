PERFEC System: Module Template
==============================

This is a template optimized for squeezing performance out of CircuitPython on a Circuit Playground Express (SAMD21).

Multiple modules help to do most or all of your development and on-board testing without having to precompile modules into `.mpy` files.

`make.py` and `make_release.py`streamline precompiling when necessary and building `.mpy` files for multiple CircuitPython releases.
